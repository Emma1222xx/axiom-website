# Portfolio Images

Place your portfolio project images in this folder.

## Instructions:
1. Add your project images here (e.g., project1.jpg, project2.jpg, etc.)
2. Update the `mockPortfolioItems` array in `src/components/Portfolio.tsx` with the correct image paths
3. Recommended image format: JPG or PNG, optimized for web (under 500KB per image)
4. Recommended dimensions: 800x800px or 1200x1200px (square aspect ratio works best)

## Example:
```javascript
const mockPortfolioItems = [
  { id: 1, title: 'Corporate Branding', category: 'Graphic Design', image: '/portfolio/branding1.jpg' },
  { id: 2, title: 'Event T-Shirts', category: 'T-Shirts', image: '/portfolio/tshirts1.jpg' },
  // ... add more items
]
```
